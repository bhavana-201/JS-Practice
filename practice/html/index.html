meta tags are HTML ele that provide metadata abt the webpage, not displayed on screen but used by browsers, search engines and web services to undertand content and purpose of page

=> type of meta data can be one of the following -
  • name attr - document-level metadata that applies to the whole page.
  • charset attr - gives the char encoding in which doc is encoded
  • content - contains the value for the http-equiv or name attribute,
  • meta property="og:*" - OpenGraph tags
  • http-equip attr

semantic HTML5:

  1. main - Only ONE "main" tag per page. Never nest it inside article tag.
  2. header - Intro content for page
  3. nav - Primary navigation links only. Not every group of links.
  4. section
  5. article
  6. aside - Content tangentially related to main (sidebars, pull quotes, ads).
  7. footer
  8. figure - Self-contained media — image, diagram, code snippet with caption.
  9. ficaption - caption for the figure tag
  10. time - Machine-readable dates/times. Always use datetime attribute.
